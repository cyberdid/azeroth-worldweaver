# Azeroth Worldweaver — коротко українською

Worldweaver — експериментальний міст між приватним сервером WoW 3.3.5a на AzerothCore/mod-playerbots та агентами Claude і Codex. Ідея — дати обом агентам спільний, перевірюваний контекст: актуальний знімок світу, журнал подій, статичні дані бази та знімок саме вікна гри.

**Це ще не готовий до встановлення реліз.** Спостерігач скомпілювали, встановили й перезапустили на приватному сервері автора. Свіжий знімок після повторного входу вже містить інвентар усіх трьох персонажів та поля атакованості й тригера для всіх 30 істот поруч; втрат подій немає. Чиста публічна збірка ще не перевірена. Мости Codex і Claude працюють, але нове повідомлення з гри після останнього перезапуску ще потрібне для перевірки обох відповідей.

Чиста публічна збірка ще не перевірена. AzerothCore має повторно сконфігурувати CMake після додавання нових `.cpp`-файлів, щоб включити модуль. Повний диспетчер природномовних ігрових дій також не завершений: зараз доступний лише обмежений набір команд playerbot.

У [головному README](README.md) є архітектурна схема, перелік можливостей, конфігурація, модель безпеки та план робіт. У публічну копію не включено приватні конфіги, паролі, серверні журнали, базу даних чи клієнтські файли.
