# Azeroth Worldweaver — коротко українською

Worldweaver — експериментальний міст між приватним сервером WoW 3.3.5a на AzerothCore/mod-playerbots та агентами Claude і Codex. Ідея — дати обом агентам спільний, перевірюваний контекст: актуальний знімок світу, журнал подій, статичні дані бази та знімок саме вікна гри.

**Це ще не готовий до встановлення реліз.** Станом на живу перевірку 2026-10-28 обидва агенти прочитали той самий свіжий знімок (послідовність 665): по 100 об’єктів поруч у контексті обсягом 61 646 символів, без обрізання контексту й втрат подій. Сервер усе ще позначає `nearby_truncated=true`, тобто завантажених об’єктів більше за ліміт 100. Чисте публічне встановлення не перевірене.

Світовий знімок до перезапуску вже містив інвентар усіх трьох персонажів, атакованість і стан тригера для істот; втрат подій не зафіксовано. Після додавання лише полів до наявного C++-файлу нову збірку виконано й сервер перезапущено. AzerothCore має повторно сконфігурувати CMake після додавання нових `.cpp`-файлів, щоб включити модуль. Повний диспетчер природномовних ігрових дій також не завершений: зараз доступний лише обмежений набір команд playerbot.

У [головному README](README.md) є архітектурна схема, перелік можливостей, конфігурація, модель безпеки та план робіт. У публічну копію не включено приватні конфіги, паролі, серверні журнали, базу даних чи клієнтські файли.
